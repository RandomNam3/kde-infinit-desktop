Update-Check in der Einstellungs-App und Verbesserungen am Installer.

## Neu

- **Update-Check:** Die Einstellungs-App sieht beim Start nach, ob es eine neue Version gibt, und zeigt auf der Startseite die Neuerungen an. **Update installieren** startet den Installer in einem Terminalfenster. Danach einmal ab- und wieder anmelden. Die automatische Prüfung lässt sich auf der Startseite abschalten.
- **Releases für jede Version:** Jede neue Version bekommt automatisch ihren Tag und ihr Release auf GitHub, mit diesen Patchnotes.

## Behoben

- **Installer unter KDE neon:** Er fragt nicht mehr bei jedem Lauf nach dem Paket `qt6-svg-plugins`, das es dort nicht gibt (neon liefert die SVG-Plugins in `qt6-svg`).
- **Installer bei einem Update:** War das Plugin schon geladen, sagt er jetzt deutlich, dass man sich ab- und wieder anmelden muss, damit KWin die neue Version lädt.

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/RandomNam3/kde-infinit-desktop/main/install.sh | bash
```

Wer schon 0.3.0 oder neuer hat, kann künftig direkt aus der Einstellungs-App aktualisieren.

Voraussetzungen: KWin 6.8 oder neuer und eine Plasma-Wayland-Sitzung.
