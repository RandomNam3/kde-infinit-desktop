Neuer Name: Aus KDE Infinit Desktop wird **KDE Infinite Desktop**.

## Geändert

- **Der Name ist jetzt korrektes Englisch.** Das betrifft das Plugin (`infinitedesktop`), die Einstellungs-App (`kde-infinite-desktop-settings`), die Notiz-App, die Pakete und das Repository [RandomNam3/kde-infinite-desktop](https://github.com/RandomNam3/kde-infinite-desktop). Alte Links leitet GitHub weiter.

## Was mit einer bestehenden Installation passiert

- **Einstellungen, Tastenkürzel, Notizen, Gruppen, Bereiche und Arbeitsflächen werden übernommen.** Beim ersten Start holen das Plugin, die Notiz-App und die Einstellungs-App sie einmalig von den alten Orten; eigene Tastenkürzel bleiben erhalten.
- **Der Installer räumt auf:** Er entfernt die Dateien, Pakete und die automatische Neuerstellung nach KWin-Updates unter dem alten Namen, damit nie beide Plugins gleichzeitig laufen.
- **Pakete** (`.deb`, `.rpm`, AUR, Gentoo) ersetzen die Pakete mit dem alten Namen.

## Installation

Direkt aus der Einstellungs-App aktualisieren oder:

```bash
curl -fsSL https://raw.githubusercontent.com/RandomNam3/kde-infinite-desktop/main/install.sh | bash
```

Danach einmal ab- und wieder anmelden.

Voraussetzungen: KWin 6.8 oder neuer und eine Plasma-Wayland-Sitzung.
